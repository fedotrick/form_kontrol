# Контроль Отливок - Web Application

## Overview

Это веб-приложение для контроля качества отливок, созданное как альтернатива PySide6 приложению, с интеграцией Google Sheets вместо Excel файлов.

## Features

- ✅ Современный веб-интерфейс с Dracula темой
- ✅ Интеграция с Google Sheets API
- ✅ Автоматический расчет "Контроль принято"
- ✅ Загрузка номеров плавок из Google Sheets
- ✅ Валидация обязательных полей
- ✅ Клавиатурная навигация
- ✅ Адаптивный дизайн для мобильных устройств

## Установка и настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка Google Sheets API

#### Способ 1: Использование service account JSON файла

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите Google Sheets API и Google Drive API
4. Создайте service account:
   - Перейдите в IAM & Admin → Service Accounts
   - Нажмите "Create Service Account"
   - Дайте имя и описание
   - Нажмите "Create and Continue"
   - Выберите роль "Editor" или "Service Account User"
   - Нажмите "Done"
5. Создайте ключ:
   - Найдите созданный service account
   - Нажмите на него
   - Перейдите во вкладку "Keys"
   - Нажмите "Add Key" → "Create new key"
   - Выберите JSON формат
   - Скачайте файл и сохраните как `service_account.json`

#### Способ 2: Использование переменной окружения

Скопируйте содержимое JSON файла в переменную `GOOGLE_SERVICE_ACCOUNT_JSON` в файле `.env`.

### 3. Настройка Google Sheets

#### Настройка листа с плавками

1. Создайте Google Sheets документ для плавок
2. Убедитесь, что у вас есть столбцы:
   - `Учетный_номер` - номера плавок
   - `Наименование_отливки` - название отливок (опционально)
3. Поделитесь доступом с email из service account JSON файла
4. Скопируйте ID документа из URL в `PLAVKA_SHEET_ID`

#### Настройка листа для контрольных данных

1. Создайте Google Sheets документ для контрольных данных
2. Поделитесь доступом с email из service account JSON файла
3. Скопируйте ID документа из URL в `CONTROL_SHEET_ID`

Или приложение автоматически создаст новый документ с именем "Control Data".

### 4. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните необходимые значения:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл:

```env
SECRET_KEY=your-secret-key-here
GOOGLE_SERVICE_ACCOUNT_PATH=service_account.json
PLAVKA_SHEET_ID=your-plavka-sheet-id
CONTROL_SHEET_ID=your-control-sheet-id
```

## Запуск приложения

### Разработка

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

### Продакшен (Gunicorn)

```bash
gunicorn app:app --bind 0.0.0.0:8000 --workers 4
```

## Использование

### 1. Выбор плавки

- В выпадающем списке выберите доступную плавку
- Система автоматически фильтрует уже обработанные плавки

### 2. Заполнение данных

- **Контроль отлито**: количество отлитых отливок
- **Дата приемки**: дата контроля (автоматически устанавливается сегодняшняя дата)
- **Контролеры**: имена контролеров (минимум один обязателен)

### 3. Указание дефектов

Заполните количество дефектов по категориям:
- **Второй сорт**: отливки, идущие во второй сорт
- **Доработка**: отливки, требующие доработки
- **Окончательный брак**: отливки, списанные в брак

### 4. Автоматический расчет

Система автоматически рассчитывает поле "Контроль принято" по формуле:
```
Контроль принято = Контроль отлито - (сумма всех дефектов)
```

### 5. Сохранение данных

Нажмите кнопку "Сохранить данные". При успешном сохранении:
- Появится уведомление об успехе
- Форма очистится
- Список доступных плавок обновится

## Клавиатурная навигация

- **↑/↓ стрелки**: перемещение между полями
- **Tab**: переход к следующему полю
- **Shift+Tab**: переход к предыдущему полю
- **Enter**: сохранение данных

## Структура данных в Google Sheets

### Лист "Control" содержит следующие столбцы:

- `Номер_плавки`
- `Контроль_отлито`
- `Контроль_принято`
- `Контроль_дата_приемки`
- `Контролер1`, `Контролер2`, `Контролер3`
- Дефекты по всем категориям

## Решение проблем

### Ошибка аутентификации Google

1. Проверьте правильность service account JSON
2. Убедитесь, что Google Sheets API включен
3. Проверьте права доступа к документам

### Ошибка загрузки плавок

1. Проверьте структуру листа с плавками
2. Убедитесь, что есть столбец "Учетный_номер"
3. Проверьте наличие плавок с "/25" в номере

### Ошибка сохранения данных

1. Проверьте заполнение обязательных полей
2. Убедитесь в правильности дат
3. Проверьте права записи в Google Sheets
