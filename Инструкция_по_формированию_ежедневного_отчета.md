## 1. Запуск приложения

1. Найдите файл `Электронный журнал контроля. Версия 3.2.1` на рабочем столе.
2. Дважды щелкните на нем для запуска.
3. Дождитесь открытия главного окна приложения "Электронный журнал контроля".

## 2. Формирование ежедневного отчета

1. В главном окне программы найдите и нажмите кнопку "Формировать отчет", расположенную в нижней части интерфейса.

2. В открывшемся диалоговом окне "Формирование отчета":
   - Выберите тип отчета "Ежедневный отчет", установив соответствующий переключатель.
   - Укажите дату, за которую нужно сформировать отчет, используя встроенный календарь.
   - Нажмите кнопку "Сформировать отчет".

3. Дождитесь сообщения об успешном создании отчета. На экране появится информационное окно с сообщением "Ежедневный отчет сохранен в файл".

4. Система автоматически откроет окно просмотра сформированного отчета.

## 3. Просмотр сформированного отчета

После формирования отчета в окне просмотра у вас есть несколько вариантов действий:

1. **Предпросмотр печати**: Нажмите кнопку "Предпросмотр печати", чтобы открыть файл отчета с помощью программы Microsoft Excel, установленной на вашем компьютере. Это позволит детально ознакомиться с содержимым отчета перед его печатью.

2. **Быстрый просмотр**: В окне просмотра отображается информация о пути к файлу и основные сведения о нем. Это дает возможность убедиться, что отчет был сформирован правильно.

## 4. Печать отчета

Для печати отчета у вас есть два варианта:

1. **Печать с двух сторон (рекомендуется)**:
   - В окне просмотра отчета нажмите кнопку "Печать с двух сторон".
   - В открывшемся диалоговом окне настройки печати выберите необходимый принтер и настройте параметры печати (качество, размер бумаги и т.д.).
   - Нажмите "Печать" для подтверждения.
   - Система напечатает первую страницу отчета.
   - После печати первой страницы появится сообщение с просьбой перевернуть лист бумаги.
   - Переверните лист в принтере согласно инструкции.
   - Нажмите "OK", чтобы продолжить печать второй страницы.
   - После успешной печати появится сообщение "Двусторонняя печать завершена успешно".

2. **Стандартная печать через Microsoft Excel**:
   - Нажмите кнопку "Предпросмотр печати" для открытия файла в Excel.
   - В Excel используйте стандартные инструменты для печати (Файл → Печать или Ctrl+P).
   - Настройте параметры печати в соответствии с вашими требованиями.
   - Нажмите "Печать" для подтверждения.
