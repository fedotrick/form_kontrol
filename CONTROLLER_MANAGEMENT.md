## 🔄 Алгоритм работы

### При запуске приложения:
1. Вызывается `load_controllers()`
2. Проверяется существование `controllers.txt`
3. Если файл есть - загружается список
4. Если файла нет - создается с контролерами по умолчанию
5. Список сортируется и используется в комбобоксах

### При нажатии "Управление контролерами":
1. Открывается `ControllerManagementDialog`
2. Загружается текущий список контролеров
3. Пользователь может добавлять/удалять контролеров
4. При нажатии "Сохранить":
   - Обновляется основной список
   - Сохраняется в `controllers.txt`
   - Обновляются все комбобоксы
   - Сохраняются текущие выборы

### При добавлении контролера:
1. Проверка на пустоту имени
2. Проверка на дублирование
3. Добавление в список
4. Обновление отображения
5. Очистка поля ввода

### При удалении контролера:
1. Проверка выбора элемента
2. Запрос подтверждения
3. Удаление из списка
4. Обновление отображения

## 📝 Инструкция по использованию

### Для добавления нового контролера:
1. Нажмите кнопку "Управление контролерами"
2. В поле "Добавить нового контролера" введите имя
3. Нажмите "Добавить" или Enter
4. Подтвердите сохранение нажав "Сохранить"

### Для удаления контролера:
1. Нажмите кнопку "Управление контролерами"  
2. Выберите контролера из списка
3. Нажмите "Удалить выбранного"
4. Подтвердите удаление в диалоге
5. Нажмите "Сохранить" для применения изменений

### Горячие клавиши:
- **Enter** в поле ввода = Добавить контролера
- **Escape** = Отменить изменения
- **Double-click** на контролере = Выбрать для удаления
